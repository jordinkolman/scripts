# Scripts 
## 1. Notion Daily Task Fetcher - `notion_daily.sh`
- Fetches tasks from Notion database and displays in terminal in categories:
  - Overdue
  - Due Today
  - Due This Week
  - Due This Sprint

## 2. Tmux Session Startup Script - `tmux_startup.sh`
- Lightweight TUI application, powered by fzf
- Allows for selection of terminal session, coding session, or standard shell
- Allows for reconnection to open tmux sessions
- Provides targeting of specific starting directories or creation of new target directory
- Starts tmux session with pre-configured layouts based on session type in targeted directory
